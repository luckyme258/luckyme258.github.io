## 具体操作提示

### 1. 单词选择策略
```python
# 优先选择有"动作感"的动词
action_verbs = ["creep", "pluck", "strand", "submerge", "synthesize"]

```

### 2. 情节构思公式
```
地点 = 银河帝国标志性地点（川陀/端点星/第二基地隐藏星球）
人物 = 谢顿计划相关者（心理史学家/第二基地成员/基地领袖）
冲突 = 内部矛盾/外部威胁/技术危机/心灵困境
单词具象化 = 将动词转化为物理/心理/科技现象
```

### 3. 语言微调指令
- 使用短句与长句交替制造节奏
- 关键动词出现时加粗或强调
- 避免形容词堆砌，用动作和细节代替
- 对话简洁，推动情节而非解释

### 4. 质量控制检查清单
✅ 单词是否自然融入情节而非刻意插入？
✅ 场景是否具有银河帝国辨识度？
✅ 是否有独特的感官细节？
✅ 结尾是否从具体情节上升到文明思考？
✅ 动词是否展示了核心含义而非边缘用法？
