# 抖音网页版弹窗问题排查与解决文档

## 📌 问题描述

在 Chrome 浏览器中访问抖音网页版（`www.douyin.com` 或 `so-landing.douyin.com`）时，频繁弹出提示框：

> "so-landing.douyin.com wants to open this application"

或 Linux 系统下出现 `xdg-open` 相关错误信息。

---

## 🔍 问题原因分析

### 根本原因

1. **抖音网页试图唤起外部应用**
   - 抖音页面中的某些链接或脚本会尝试通过**自定义协议**调用本地应用（如抖音客户端）
   - 涉及的协议包括：`snssdk://`、`snssdk1128://`、`bytedance://`、`bitbrowser://`

2. **系统找不到对应应用**
   - Linux 环境下，`xdg-open` 找不到能处理这些协议的应用
   - Chrome 将请求交给系统后，系统反馈失败，弹出提示

3. **浏览器设置无法完全阻止**
   - Chrome 的"网站设置" → "Apps on device" 设置为 Block 后，弹窗仍然出现
   - 说明弹窗可能来自多个域名或由 JS 动态触发

### 为什么油猴脚本无效？

| 尝试方法 | 失败原因 |
|---------|---------|
| 拦截 `location.href` | `Cannot redefine property: href` — 抖音锁定了 location 对象 |
| 拦截 `location.replace` | `Cannot assign to read only property 'replace'` — 只读属性无法覆盖 |
| 拦截 `window.open` | 部分可拦截，但协议跳转不走这个路径 |
| 拦截 a 标签点击 | 弹窗不是由用户点击触发的 |

**结论**：抖音页面有安全防护，油猴脚本在 JS 层面无法完全拦截协议跳转。

---

## ✅ 解决方案

### 方案一：Chrome Policy（推荐，100%有效）

在浏览器底层拦截自定义协议，网页 JS 无法绕过。

#### 操作步骤

**1. 创建 Chrome 政策目录**

```bash
sudo mkdir -p /etc/opt/chrome/policies/managed
```

**2. 创建政策文件**

```bash
sudo tee /etc/opt/chrome/policies/managed/block-douyin-protocols.json > /dev/null << 'EOF'
{
  "URLBlocklist": [
    "snssdk://*",
    "snssdk1128://*",
    "bytedance://*",
    "bitbrowser://*"
  ]
}
EOF
```

**3. 验证文件内容**

```bash
cat /etc/opt/chrome/policies/managed/block-douyin-protocols.json
```

预期输出：
```json
{
  "URLBlocklist": [
    "snssdk://*",
    "snssdk1128://*",
    "bytedance://*",
    "bitbrowser://*"
  ]
}
```

**4. 重启 Chrome**

```bash
pkill chrome
```
然后重新打开 Chrome。

**5. 验证政策生效**

在 Chrome 地址栏输入：
```
chrome://policy
```
确认 `URLBlocklist` 出现在列表中，且值正确。

**6. 测试**

访问抖音网页版，弹窗应消失。

---

### 方案二：浏览器网站设置（部分有效）

1. 访问 `https://www.douyin.com`
2. 点击地址栏左侧的锁图标
3. 选择"网站设置"
4. 找到 **"Apps on device"**（设备上的应用）
5. 设置为 **"Block"**

⚠️ **注意**：此方法可能不完全生效，因为弹窗可能来自多个域名。

---

### 方案三：其他浏览器参数（备选）

如果上述方法无效，可尝试启动 Chrome 时禁用外部协议处理：

```bash
google-chrome --disable-features=ExternalProtocolDialog
```

此参数会禁用外部协议对话框，但可能影响其他网站的正常功能。

## 🛠️ 故障排查

### 检查 Policy 是否生效

```bash
# 查看政策文件权限
ls -la /etc/opt/chrome/policies/managed/

# 查看 Chrome 政策日志
google-chrome --enable-logging --v=1 2>&1 | grep -i "blocklist"
```

### 删除 Policy（如需恢复）

```bash
sudo rm /etc/opt/chrome/policies/managed/block-douyin-protocols.json
pkill chrome
```

### 查看系统中注册的协议

```bash
grep -r "snssdk\|bytedance\|bitbrowser" ~/.local/share/applications/ ~/.config/ 2>/dev/null
```

## 📝 总结

1. **问题本质**：抖音网页试图通过自定义协议唤起外部应用，Linux 系统找不到处理程序
2. **油猴脚本无效**：抖音页面锁定了 `location` 对象，JS 层无法拦截
3. **根本解决方案**：使用 **Chrome Policy** 在浏览器底层拦截协议
4. **关键命令**：创建 `/etc/opt/chrome/policies/managed/block-douyin-protocols.json`
