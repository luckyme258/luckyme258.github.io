## 📝 使用建议

### 学习优先级

| 优先级 | 词表 | 学习方式 |
| :--- | :--- | :--- |
| **P0 必学** | 表1中除人名和专有名词外的普通词汇 | 背诵变形 + 阅读中巩固 |
| **P1 了解** | 表2中的关键词 | 阅读时查一下即可 |
| **P2 认识即可** | 表1中的人名 | 知道是谁就行，不用背 |
| **P3 专有名词** | CDF, BrainPal, CU, SmartBlood, Consu等 | 知道含义即可 |
